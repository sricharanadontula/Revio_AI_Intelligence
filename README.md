# Revio - AI-Powered Customer Feedback Intelligence

A prototype dashboard for restaurant feedback analysis.

## Features
- Aspect-based sentiment analysis
- Complaint discovery
- Emerging complaint alerts
- Business recommendations
- Customer review explorer

## Technology
- Python
- Streamlit
- Pandas
- Plotly

## Demo Data
This public demonstration uses entirely synthetic restaurant reviews.
It does not contain real Yelp data, live Revio data, or actual customer feedback.

## Run Locally
pip install -r requirements.txt

streamlit run app.py
